# 6. SECTION 02 — THE PROBLEM

### Heading
**The problem was not a lack of power. It was fragmentation.**

Use the source problem statements, rewritten into concise portfolio language while preserving meaning:

1. Users often manage separate devices for charging, power backup and ambient/power-related functions.
2. Multiple cords and scattered gadgets create friction and visual clutter.
3. Traditional power backups and charging stations can feel bulky, dated and unintuitive.
4. The disjointed setup affects both usability and the calmness of the user's environment.

Use a large product image beside the problem statement.

Then create four visual pain-point blocks:

**CLUTTER**

**FRAGMENTATION**
Charging, backup and control are handled through separate interactions.

**BULK**
Existing power-backup products prioritize utility over everyday integration.

**DISCONNECTED EXPERIENCE**
Power management becomes something users have to actively manage rather than something that quietly supports them.
