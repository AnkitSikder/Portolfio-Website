# ASR Dashboard

The Area Sales Representative (ASR) Dashboard in the Jio-bp Incident Management System focuses on multi-site oversight and provides hierarchical roll-ups of safety performance metrics across different regions and clusters.

## Key Screens
*   **01-asr-dashboard-full.png**: Full view of the ASR dashboard interface, showing KPI cards aggregating incident totals from multiple facilities.
*   **02-asr-facility-dropdown.png**: The facility selector dropdown used to context-switch between domains like "Petro Retail HSE", "Retail Operations", "Road Logistics", etc.

## Core Interactions
*   **Facility Switching**: The top navigation features a robust facility selector allowing the Area Manager to drill into specific business functions.
*   **Global Search Palette**: Pressing the search bar brings up a command palette with pills filtering by "Incidents", "Employees", and "Locations".
*   **Data Aggregation**: Unlike the RO dashboard which displays metrics for a single mobility hub, the ASR view aggregates these figures at a regional scale, facilitating comparisons and identifying systemic trends.
*   **Learning & Compliance**: The "Learning from Incidents" module ensures the ASR has access to the latest policy frameworks and root cause analyses to disseminate best practices down to the Retail Operators.

## UI/UX Notes
*   Maintains the same design language as the RO dashboard but shifts the persona focus from local tactical management to regional strategic oversight.
*   User context (Ashwin Suresh - ASR) persists the role-based experience framework.
