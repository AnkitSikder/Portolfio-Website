# RO Dashboard

The Retail Operator (RO) Dashboard is the primary operational interface for site managers at Jio-bp Mobility Hubs. It provides localized oversight for incidents, safety achievements, and site profile metrics.

## Key Screens
*   **01-ro-dashboard-full.png**: The full RO dashboard showing KPI counts, recent incidents table, active incidents list, and the gamification/achievement banner.
*   **02-ro-notifications.png**: The notification dropdown detailing system alerts and incident updates.
*   **03-ro-search-palette.png**: The global command palette search interface.
*   **04-ro-filter-panel.png**: The advanced filtering side panel for the incident data table.
*   **05-ro-report-modal.png**: The Report Incident modal triggered via the primary CTA.
*   **06-ro-incident-detail.png**: The detailed incident review modal showing the timeline and attributes of a specific incident.

## Core Interactions
*   **KPI Cards**: Top-level metric cards indicating Total, Draft, In Progress, Rejected, and Closed incidents.
*   **Gamification**: The "Safety Champion" badge system rewards operators for adhering to safety protocols, driving engagement.
*   **Incident Table**: A sortable, filterable data grid listing recent incidents with severity badges and status indicators.
*   **Active Incidents Pane**: A right-side panel tracking ongoing issues that require immediate action or monitoring.
*   **Learning from Incidents**: An interactive carousel displaying safety advisories and case studies.

## UI/UX Notes
*   Optimized for operational efficiency, ensuring that the most critical information (KPIs, Active Incidents) is immediately visible without scrolling.
*   Uses a split-pane layout to balance data density with readability.
